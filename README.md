# ILMORA

## Research. Discover. Verify.

ILMORA is an AI-Assisted Islamic Research workspace designed to help users explore scholarly literature, retrieve evidence, compare viewpoints, and trace findings back to original sources.

---

## Product Principle

> The sources are the authority. AI is the research assistant.

---

## Current MVP

The current version includes:

- ILMORA branded Gradio interface
- Research workspace
- Scholarly library architecture
- PDF ingestion
- Text cleaning
- Chunking
- Multilingual embeddings
- Chroma vector database
- BM25 keyword search
- Hybrid retrieval architecture
- Reranking
- Citation/evidence structure
- Groq integration point
- Built-in library architecture
